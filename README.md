# Gastos Java

Aplicación de consola desarrollada en Java para administrar gastos personales.
Permite llevar un control de los gastos y conocer cuánto dinero se ha gastado durante el mes.

## Uso

Con este programa puedes:

- Registrar nuevos gastos personales.
- Consultar los gastos registrados.
- Calcular el total de gastos del mes.
- Guardar la información en un archivo para conservar los registros.

## Cómo ejecutarlo

Para ejecutar el programa desde la terminal, sigue estos pasos:

1. Abrir la terminal dentro de la carpeta del proyecto.

2. Compilar el archivo Java:

   ```bash
   javac Gastos.java
   ```

3. Ejecutar el programa:

   ```bash
   java Gastos
   ```

4. Seguir las opciones que aparecen en la consola para registrar o consultar tus gastos.
